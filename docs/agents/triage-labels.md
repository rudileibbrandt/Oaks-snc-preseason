# Triage labels — mapped to this repo's states

| Label in mattpocock/skills | Here |
|---|---|
| `needs-triage` | Unchecked TODO.md line without a done-condition |
| `needs-info` | TODO.md line carrying an open question for Rudi |
| `ready-for-agent` | TODO.md checkbox with a verifiable done-condition |
| `ready-for-human` | Line tagged `(Rudi)` — decision or real-user data touch needed |
| `wontfix` | Struck-through line with the reason kept |
| `bug` | TODO line that names a repro (see `diagnosing-bugs`) |
| `enhancement` | Any other TODO line |
